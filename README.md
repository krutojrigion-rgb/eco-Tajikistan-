# eco-Tajikistan-
«ЭкоКарта Таджикистана» — образовательный проект, посвящённый экологии нашей страны. Сайт содержит интерактивную карту, информацию о реках, ледниках, горах и экологических проблемах. Цель проекта — повысить экологическую грамотность молодёжи и привлечь внимание к сохранению природы Таджикистана.  Создатели: Каримов Халил и Якубова Гульнора.
